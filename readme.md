# Lift Manager - Διαχείριση Πιστοποιητικών & Οικονομικών Ανελκυστήρων

Εφαρμογή web για την παρακολούθηση πιστοποιητικών, ημερομηνιών λήξης, οικονομικών εκκρεμοτήτων και συντηρητών πολυκατοικιών.

## ✨ Χαρακτηριστικά
- **Πιστοποιητικά:** Παρακολούθηση κατάστασης (Σε ισχύ, Υπό έκδοση, Ληγμένα).
- **Οικονομική Παρακολούθηση:** Υπολογισμός κόστους, προκαταβολών και υπολοίπων ανά πολυκατοικία.
- **Συντηρητές:** Διαχείριση στοιχείων επικοινωνίας και αποστολή αναφορών via Email.
- **Εκτύπωση & PDF:** Δυνατότητα εκτύπωσης καθαρών αναφορών.
- **Cloud Database:** Ασφαλής αποθήκεωση δεδομένων μέσω Supabase.

## 🛠️ Τεχνολογίες
- HTML5, CSS3, JavaScript (Vanilla)
- Supabase (Backend Database)
- GitHub Pages (Hosting)
